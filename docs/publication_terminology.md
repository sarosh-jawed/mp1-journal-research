# Publication terminology contract

Apply this contract to E code labels, rendered tables/figures, the V3 rewrite and all new
manuscript-facing text. Preserve literal source headers and historical accepted artifacts;
changing those would break provenance. Historic language is quoted only to identify a required
removal or explain the original source. An occurrence in a prohibition is not an endorsed claim.

| Use | Do not use as a result claim | Reason / claim IDs |
|---|---|---|
| Released records; exact repeated full-record patterns | Verified unique respondents; duplicate people | A01, B10 |
| Source-defined sections | Validated five-subscale instrument | B02-B06 |
| Reported reduction in independent thinking (D5 CT) | Critical-thinking ability; demonstrated erosion | B06 |
| D5_P1/P2 and D3_P1/P2; unordered descriptive profiles | Independent/Assisted/Dependent/Over-reliant types; four tiers | B07-B10 |
| Same-record perturbation stability | External validation; predictive accuracy | B09 |
| Quality sensitivity with all primary records retained | Cleaning/removal of invalid respondents | B01 |
| Conditional ordinal omega of latent responses | Reliability of observed sums inferred from omega | B02 |
| Accepted predictive-feasibility blocker | Successful prediction, SHAP, LIME or calibration | C02-C04 |
| Self-reported CGPA bands; nominal profile comparison | Exact GPA means; grade midpoints; ordered-profile trend | D01-D05 |
| Very small and inconclusive | No effect; equivalence; harm; benefit; reversed hypothesis | D02-D04 |
| Conditional percentile interval with unit assumption | Unqualified population confidence interval | D04 |
| Compatibility audit; within-country observed-item association | International validation; replicated profiles; latent equivalence | D06-D12 |
| Literal institution label | Verified university sampling cluster | A04, D04 |
| USA / Indonesia separately; U.S.-Indonesia in prose | Pooled country effect; Bangladesh latent transfer | D06-D12 |

Machine sample identifiers remain `full`, `sensitivity`, `quality_fixed_profiles`,
`quality_refit_profiles`, `sensitivity_fixed_target` and `sensitivity_refit_target` as used in
accepted files. Display labels explain fixed versus refitted target without silently equating
the D5 and D3 sensitivity definitions. Item IDs always resolve to the accepted inventories.
